# Featured Projects

## Infrastructure Automation Platform with Ansible AWX

Repository  
https://github.com/vijaymanda06/AWX-Automation-EKS

Infrastructure automation platform built on Kubernetes using AWS EKS and Ansible AWX.

Key implementation details

- Infrastructure provisioning using Terraform  
- Kubernetes control platform deployed on Amazon EKS  
- AWX deployed using Helm  
- GitLab CI pipeline triggering automation workflows through the AWX API  
- Infrastructure automation using AWS Systems Manager instead of SSH access

## Self Hosted Kubernetes Platform (RKE2 Homelab)

Repository  
https://github.com/vijaymanda06/My-Home-lab

Production-style Kubernetes platform used to experiment with platform engineering, observability, and DevSecOps tooling.

Key implementation details

- Three node Kubernetes cluster using RKE2 with KVM worker nodes  
- MetalLB configured for bare-metal LoadBalancer services  
- Longhorn distributed storage for persistent workloads  
- Prometheus and Grafana monitoring stack for cluster observability  
- New Relic integration for application performance monitoring  
- Falco runtime security using eBPF for threat detection  
- Kubescape compliance scanning against MITRE ATT&CK and NSA CISA frameworks  
- Secure remote cluster access using Tailscale VPN
